# Yocto Project Learning

## Overview

This repository documents my learning and practical experience with the Yocto Project while working on Embedded Linux development.

The content is based on my work with Intel x86, Raspberry Pi CM4, and TI AM62 platforms.

The goal of this repository is to document concepts I learned, common build issues, and practical workflows used while developing custom Linux images.

> Note:
> This repository contains only my learning notes, simplified examples, and generic configurations. It does not include proprietary source code or confidential project information.
